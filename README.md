# 3D Engine Test

This project is a small 3D engine to allow me to learn the princpiples of rasterization, object management, and 3D rendering in general! It's written entirely in julia, and is also entirely CPU bound. I'm working on making it GPU supported, although it would only be for Intel GPUs, since I have an Intel Arc. I'm also planning on integrating an animation engine later on, and even later on, a physics engine, but that may take a whole lot of time before we actually get there, and I may move onto vulkan before then. I also currently have only one light available, but I also plan on adding in more. Finally, there's a way to import obj files directly into the code, but I have not tested that function directly yet, so, feel free to give me any feedback if anything is not working, or to corrcet it yourself if you're motivated.
